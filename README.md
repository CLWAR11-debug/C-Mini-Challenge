# C-Mini-Challenge
This C++ project demonstrates Stack Abstract Data Type
This MiniChallenge project demonstrates how a stack can be used to convert a decimal number into its binary representation. By repeatedly dividing the decimal value by two and storing each remainder on a stack, the program takes advantage of the stack's Last-In, First-Out (LIFO) behavior to output the binary digits in the correct order. In addition to illustrating the binary conversion algorithm, the project reinforces key C++ programming concepts such as abstract data types, inheritance, templates, dynamic memory management, encapsulation, constructors and destructors, and fundamental stack operations. Overall, the project serves as an excellent introduction to both the Stack ADT and the practical application of object-oriented programming principles in C++.
